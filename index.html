Sobre mí

Descripción

Consultor informático en VCE Consulting, enfocado en la operación y el análisis de infraestructura en Oracle Cloud Infrastructure (OCI) para clientes empresariales y en la integración de Oracle APEX con JD Edwards.

Por fuera de la consultoría, desarrollo sistemas web a medida con Laravel como freelance y construyo Komio, un producto propio en desarrollo.

Mi diferencial es la forma de trabajar: integro agentes de IA (Claude Code, Antigravity, VS Code con asistentes) en el flujo diario de operación y desarrollo. No los uso como chat, sino como herramientas de ingeniería: con habilidades (skills) documentadas, servidores MCP conectados a OCI y a bases de datos, memoria persistente y procedimientos claros, siempre con criterio humano y validación antes de cada acción en producción.

Detalle de ítems · Áreas de trabajo

1

Infraestructura y operación en OCI

  • Análisis y operación de infraestructura en múltiples tenancies y compartments de clientes empresariales.
  • Redes: VCN, subredes, route tables, security lists, NSG, Local Peering Gateways (LPG), DRG.
  • Load Balancers: listeners, backends, certificados SSL y routing policies.
  • Acceso seguro: OCI Bastion (sesiones con varios saltos), SSH por peering e instance principals.
  • Seguridad y gobierno: Cloud Guard, políticas IAM, dynamic groups, compartments.
  • Cómputo y almacenamiento: instancias, shapes flex, block volumes, Object Storage.
  • Automatización con OCI CLI y SDK.
  • Monitoreo de servidores Oracle Linux y Windows Server (logs de SO, Oracle Database, WebLogic y Event Viewer) e informes técnicos y ejecutivos con planes de acción priorizados.
2

Integración Oracle APEX ↔ JD Edwards

  • Integración directa sobre los esquemas de base de datos de JD Edwards con SQL y PL/SQL.
  • Integración a través del servidor AIS / Orchestrator de JD Edwards (REST, alojado en WebLogic) como capa orquestadora.
  • Oracle APEX como capa de traducción cuando Orchestrator no puede hablar SOAP: servicios SOAP del WMS de un operador logístico consumidos con APEX_WEB_SERVICE + PL/SQL.
  • Hubs de facturación electrónica APEX ↔ JDE ante la DIAN a través de proveedores tecnológicos: emisión, consulta de estado, reemisión de rechazados y monitor operativo.
  • Portal de Proveedores: autogestión de facturación, pagos y certificados de retención.
  • Recepción EDI de órdenes de compra de un retailer hacia JD Edwards.
  • Desarrollo en Oracle APEX 26.1 con APEXlang (.apx), versionado en Git y validado con SQLcl.
3

Desarrollo a medida con Laravel

  • Sistemas web a medida como freelance, de punta a punta.
  • Laravel 13 + Inertia/React, funciones en tiempo real e impresión térmica.
  • Integración con facturación electrónica DIAN.
  • PostgreSQL y pruebas automatizadas con Pest.
4

Automatización y agentes de IA

  • Flujos con n8n: facturación electrónica (Dataico/DIAN), recepción de facturas de proveedores, integración con ERP y Google Drive.
  • Agentes de IA (Claude Code, Antigravity) con skills, servidores MCP y memoria persistente, siempre con validación humana antes de cada acción en producción.
  • Despliegue de servicios en contenedores (Docker, Dokploy).
